# LM-Router

사용자의 질의와 에이전트 실행 상태에 따라 답변 품질을 유지하면서 작업 완료 비용을 줄이는 모델 라우터를 연구합니다. 라우터를 별도로 학습하지 않는 접근을 우선합니다.

현재는 자료조사와 설계 후보 검토 단계입니다. 구현이나 성능 검증이 완료된 상태는 아닙니다.
